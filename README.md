# Raul Adriano Jardim — Portfólio

Portfólio pessoal de Raul Adriano Jardim, estudante de Análise e Desenvolvimento de Sistemas (ADS) na UNICID, com interesse em desenvolvimento, dados e suporte em TI.

## Áreas de interesse e estudo

- Desenvolvimento backend e APIs REST
- Desenvolvimento frontend e integração com APIs
- Python, FastAPI e SQLAlchemy
- Java e Spring Boot
- SQL e bancos relacionais
- Python e Pandas para análise de dados
- Power BI e DAX
- Docker, pytest e Git

## Projetos apresentados

### Auth Customer API
API de autenticação em FastAPI com JWT, bcrypt, Pydantic e SQLAlchemy.

### Employee Management API
API REST em Java/Spring Boot para gerenciamento de funcionários, com arquitetura em camadas e tratamento de exceções.

### Segmentação de Clientes — Curva ABC
Projeto de análise em SQL Server utilizando CTEs e Window Functions.

### Dashboard de Vendas
Dashboard desenvolvido em Power BI para análise de indicadores de vendas.

### Análise de Performance Logística — E-commerce Olist
Projeto de análise de dados com Python e Pandas a partir do dataset público do Olist.

## Tecnologias do portfólio

O site é construído com HTML5, CSS3 e JavaScript, sem framework ou etapa de build.
